# **COLD EMAIL FRAMEWORK**

  

Use the **3C Framework**:

  

1️⃣ Compliment

2️⃣ Case Study

3️⃣ Call to Action

  

Compliment:

Must be specific and prove the email was personalized.

  

Case Study:

Provide a short outcome-focused result.

  

CTA:

Low-friction question encouraging reply.

  

Example structure:
Subject: Question for {{Name}}

Hey {{Name}},

{{Specific compliment}}

Recently helped {{creator}} achieve {{result}}.

Worth showing you how we did it?

# **EMAIL INFRASTRUCTURE**

  

Cold email must follow professional deliverability rules.

  

Key rules:

1. Never send outreach from main domain
    
2. Use **burner domains**
    
3. Use tools like Instantly for sending campaigns
    
4. Use warmed inboxes
    
5. Send at scale (~1000 leads/month)

# **SALES PHILOSOPHY**

  

Sales calls follow a **diagnostic approach**.

  

Do not behave like a pushy salesperson.

  

Instead act like a **doctor diagnosing a problem**.

  

Call structure:

1. Rapport
    
2. Agenda
    
3. Discovery
    
4. Identify gap
    
5. Present solution
    
6. Close
    

  

Business owners buy based on logic:
Will this make me more money than it costs?

# **OBJECTION HANDLING**

3. Clarify real objection
    
4. Address root concern
    
5. Return to close
