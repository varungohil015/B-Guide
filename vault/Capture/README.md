# Capture

This folder is the fast drop zone for anything ziscol wants to remember later.

## Purpose
Use this folder to dump:
- work tasks
- personal tasks
- random ideas
- things to ask Alfred later
- errands
- reminders
- opportunities
- half-formed thoughts

## Rule
Capture fast. Organize later.

## Keyword rule
If ziscol uses the keyword `random`, Alfred should treat the message as a capture request and file it in the most appropriate note or folder.

## Suggested files
- `Inbox.md` — default place for quick captures
- `Work.md` — work-related tasks or ideas
- `Personal.md` — personal tasks or reminders
- `Questions for Alfred.md` — things to ask later

The goal is to never lose a thought just because it showed up at a random time.
