# 13 Schedule Logic

## Objective
Balance three realities:
1. current client cash flow is necessary
2. agency building must happen daily or growth stalls
3. skill-building/exploration should support leverage, not become avoidance

## Scheduling philosophy
Use Matt Gary-style energy allocation:
- best mental hours -> growth
- mid-day -> cash flow work / delivery
- late day -> review, planning, light systems, learning tied to immediate execution

## Current business reality
- 2 active clients
- cash flow needed for loan obligations and operating flexibility
- agency building cannot be delayed indefinitely
- exploration/building tools should not eat peak hours

## Core rule
Do not put client editing in Founder Flow unless there is a hard deadline emergency.

## Daily block structure
### Morning routine
- wake / gym / shower / breakfast / setup

### 9:00 AM - 1:00 PM
- Founder Flow
- sales
- offer
- outreach
- systems
- agency growth
- no client editing unless urgent

### 1:00 PM - 2:00 PM
- lunch / reset

### 2:00 PM - 5:00 PM
- client work / delivery / review
- this is the cash flow block

### 5:00 PM - 6:30 PM
- agency execution second block
- follow-ups / content / ops / outreach / proofs

### 6:30 PM - 7:00 PM
- tomorrow planning

### Optional late block (only if needed)
- 8:00 PM - 9:00 PM
- light learning / tool building / cleanup
- not heavy reactive work

## Skill-building rule
Only schedule skill-building if it directly helps:
- close clients faster
- fulfill better with less effort
- build systems/tools that save time

If not directly useful, it goes to optional block or weekend.

## Priority order
1. cash flow survival
2. agency scaling blocks every day
3. systems and delegation
4. skill-building that compounds
5. random exploration last
