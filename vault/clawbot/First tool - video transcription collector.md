# First tool - video transcription collector

## Status
Saved as a potential first Clawbot tool.

## Core idea
Build a tool that gets transcription of videos one by one and stores them in a clean usable format.

## Why this matters
ziscol already has a NotebookLM with a lot of Matt Gary content. If video transcriptions are collected in one place, Alfred can reference higher-quality source material when helping with:
- business decisions
- strategy
- agency ideas
- offer refinement
- systems thinking
- content principles

## Main goal
Create a reliable way to turn videos into accessible text so the best ideas and principles can be searched, reused, and applied.

## Value to business
- better reference material
- faster idea extraction
- easier principle-based decision support
- more leverage from existing educational content
- reduced friction when turning videos into notes or strategy

## Best initial version
### MVP
- input one video at a time
- generate transcript
- save transcript in a clean note/file
- include title, source, date if possible
- keep formatting simple and searchable

## Nice future additions
- summary generation
- key insights extraction
- action items extraction
- tagging by topic
- source links
- searchable archive across all transcriptions
- optional clean transcript output with timestamps removed for easier reading and context use

## Questions to evaluate later
- Where will the videos come from?
- Are these local files, YouTube links, or exported NotebookLM sources?
- Is the best path to transcribe directly, or import existing transcript text?
- What format should output use in Obsidian?
- Do we want just raw transcript, or transcript + summary + key principles?

## Initial recommendation
This is a good first internal tool idea because it creates a stronger knowledge base for better future decisions.
It is probably more valuable as an internal leverage tool than as a public product right now.
