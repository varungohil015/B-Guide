# clawbot

This folder is for collecting anything related to making the most out of Clawbot.

## Purpose
Track:
- use cases for Clawbot
- upgrade ideas
- workflow ideas
- cost-efficient AI/model choices
- automation opportunities
- experiments
- limitations and lessons

## Structure
- `00 Inbox.md` — quick captures and loose ideas
- `01 Use Cases.md` — real use cases worth implementing
- `02 Upgrades.md` — feature or workflow improvements
- `03 Cost Efficiency.md` — model/provider choices, tradeoffs, and cost notes
- `04 Experiments.md` — tests to run
- `05 Lessons.md` — what worked, what failed, and what to change
- `tools/` — active tool project folders

Keep it practical. Save ideas fast, refine later.
