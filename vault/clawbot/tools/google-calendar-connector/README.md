# google-calendar-connector

Google Calendar connector project for Clawbot.

## Current target account
- notfakeytch@gmail.com

## Commands
- `list-calendars`
- `upcoming`
- `today`
- `create-event`
- `create-block`
- `delete-event`
- `find-events`
- `upsert-block`

## Scripts
- `setup.sh` — one-time dependency install
- `run.sh` — normal command execution without pip spam
