# mac-command-bridge

Controlled execution bridge for letting Alfred trigger approved actions on the user's Mac mini / Mac.

## Purpose
Remove repetitive copy-paste execution by introducing a safe bridge between Alfred and local tools.

## Principle
Not full shell access.
Only controlled, allowlisted actions.

## Current state
- runner skeleton created
- calendar actions wired first
- watched-folder architecture ready for local testing
- supports create, read, delete, find, and upsert calendar actions
