# Master Rules

## Practical rules repeated across the folder

1. **Start narrow.**
   - Pick one job, one workflow, one niche, one persona.
   - Broad/generic loses.

2. **Automate mechanics first, not judgment first.**
   - AI is strongest on repetitive, structured, high-frequency work.

3. **Data quality is the moat.**
   - Better inputs, better enrichment, better memory, better style guides, better outputs.

4. **Manual first, then automate.**
   - Do the workflow yourself before turning it into an agent/system.

5. **Closed loops win.**
   - Action -> metric -> learning -> improved next action.

6. **Use strong models for risky tasks.**
   - Safety, prompt injection resistance, planning, public outputs.

7. **Least privilege always.**
   - Give the agent only the access it needs.

8. **Separate contexts.**
   - Separate channels/personas/workspaces for distinct responsibilities.

9. **Write things down.**
   - Memory and process only improve if stored in files/docs/templates.

10. **Human review at high-risk moments.**
   - Public posting, payments, prod deploys, sensitive communications.

11. **Optimize for outcomes, not appearances.**
   - Views are not revenue. Pretty outputs are not business value.

12. **Use AI to improve its own workflow.**
   - Dashboards, trackers, self-generated skills, reusable process assets.

13. **If people already pay for it, it’s easier to productize.**
   - Upwork, agency work, manual services are signal.

14. **Subniche > big vague market.**
   - Easier positioning, easier SEO, easier trust, easier product design.

15. **AI-search world favors specific, structured, useful pages.**
   - Especially local / comparison / decision-stage content.

16. **Style should be codified.**
   - Templates, prompt guides, style guides, storyboard formats.

17. **Do fewer bigger writes when possible.**
   - Better than lots of fragmented low-quality agent actions.

18. **Don’t over-trust toy demos.**
   - Real value = repeatable workflow + reliability + measurable outcome.
